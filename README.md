# trabajo-extraclase-
Método del Codo: La gráfica muestra cómo disminuye la suma de cuadrados intra-cluster (WCSS) a medida que aumenta k. El punto donde la disminución se vuelve menos pronunciada (el "codo") sugiere el número óptimo de clústeres.

2. Coeficiente de Silueta: La gráfica muestra los valores del coeficiente para diferentes valores de k. El valor de k con el coeficiente más alto indica el número óptimo de clústeres.

3. Visualización de Clústeres: Finalmente, se muestra una visualización de los datos agrupados según el valor óptimo de k determinado por el coeficiente de silueta.

Conclusiones

Ambos métodos proporcionan información valiosa para determinar el número óptimo de clústeres. El método del codo es más subjetivo ya que requiere identificar visualmente el "codo", mientras que el coeficiente de silueta proporciona una medida cuantitativa. En la práctica, es recomendable usar ambos métodos en conjunto para tomar una decisión más informada.
